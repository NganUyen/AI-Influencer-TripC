# Application Configuration

This directory contains configuration files for various services and features.

## Files

- `platforms.ts` - Social media platform configurations
- `constants.ts` - Application-wide constants
- `features.ts` - Feature flags and toggles

## Platform Support

Current supported platforms:

- Twitter / X
- LinkedIn
- Facebook
- Instagram
- TikTok
- YouTube

Each platform has specific configuration for:

- API endpoints
- OAuth credentials
- Rate limits
- Content format requirements
